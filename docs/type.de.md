## Typ (Datei / Ordner)

Der **Typ** legt fest, ob an dieser Stelle eine **Datei** oder ein **Ordner** erzeugt wird.

### Verhalten im Editor:

- **Hat ein Eintrag Unterelemente**, wird automatisch ein **Ordner** erzeugt.  
  In diesem Fall ist die Einstellung fest vorgegeben und kann nicht geändert werden.

- **Hat ein Eintrag keine Unterelemente**, wird standardmäßig eine **Datei** erzeugt.  
  Durch Aktivieren der Checkbox kann stattdessen ein **Ordner** erzeugt werden.

### Zusammenfassung:

- Unterelemente vorhanden → **Ordner**
- Keine Unterelemente + Checkbox aus → **Datei**
- Keine Unterelemente + Checkbox an → **Ordner**
