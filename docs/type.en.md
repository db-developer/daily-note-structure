## Type (File / Folder)

The **type** defines whether a **file** or a **folder** is created at this position.

### Editor behavior:

- **If an entry has child elements**, it is automatically treated as a **folder**.  
  In this case, the setting is fixed and cannot be changed.

- **If an entry has no child elements**, a **file** is created by default.  
  By enabling the checkbox, a **folder** can be created instead.

### Summary:

- Children present → **Folder**
- No children + checkbox off → **File**
- No children + checkbox on → **Folder**
